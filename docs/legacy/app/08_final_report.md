# 08. 최종 보고 (Game View Remote 폰 앱)

작성: 2026-11-14 새벽, 최종 단계 작업자. 주인이 읽는 문서입니다.

이번 최종 단계에서도 실제 폰은 쓰지 않았습니다. 시험은 PC 안의 안드로이드 가상 기기(일련번호 `emulator-5554`)와 PC 스크립트로 했습니다. 커밋은 하지 않았습니다. 방화벽을 바꾸지 않았고 관리자 확인 창(UAC)도 띄우지 않았습니다.

## 3. 쓰는 방법

### QR 로 (기본)

1. PC 와 폰을 **같은 Wi-Fi** 에 연결합니다.
2. Unity 메뉴 **Tools > Game View Remote > Window** 를 엽니다.
3. 맨 위의 **Start** 를 누릅니다. QR 이 나옵니다. Play 를 누르지 않아도 됩니다.
4. 폰의 **기본 카메라**로 QR 을 비추고, 뜨는 링크를 누릅니다.
5. **처음일 때**: 페이지에서 **[앱 설치(APK 받기)]** 를 누릅니다. 브라우저가 경고하면 계속 받기를 고릅니다. 받은 파일을 열어 설치합니다. "출처를 알 수 없는 앱"을 물으면 그 브라우저를 허용합니다. Play 프로텍트가 물으면 "검사 없이 설치"를 고릅니다. 페이지로 돌아와 **[여기를 눌러 연결]** 을 누릅니다.
6. **앱이 이미 있을 때**: 페이지에서 **[앱으로 열기]** 만 누릅니다.
7. 앱이 "PC(주소)에 연결할까요?" 를 물으면 **[연결]** 을 누릅니다. 직접 찍은 QR 일 때만 누르세요.
8. Unity 에서 **Play** 를 누릅니다. 폰에 게임 화면이 나옵니다. 폰을 터치하면 게임이 반응합니다.
9. 다음부터는 폰에서 앱만 열면 됩니다.

글자를 입력하는 단계는 없습니다. "다른 기기가 보고 있습니다"가 나오면 **[여기서 보기]** 를 누릅니다.

### USB 케이블로 (QR 이 안 될 때)

창의 "QR 이 안 될 때" 구역에 **[USB 로 앱 설치]**, **[USB 로 연결]** 이 있습니다. 방화벽과 무관하게 동작합니다. **지금은 이 버튼들이 가상 기기에만 동작하도록 잠겨 있습니다**(7장 4번). 예전의 Chrome 페이지 방식(USB 로 꽂고 "폰에서 열기")은 그대로 됩니다.

## 4. 무엇을 어떻게 확인했나

"가상 기기" = 이번 최종 단계에서 PC 의 안드로이드 가상 기기로, 최종 앱 파일(0.1.2, 해시 `a07bad64…`)로 확인. "PC 스크립트" = 폰 없이 PC 에서 서버에 직접 붙어 확인. "실제 폰" = 지시로 폰 사용을 멈추기 전, 11-14 00:37~00:57 경 Galaxy Z Flip5 에서 **옛 앱 0.1.0** 으로 확인.

## 5. 매끄러움에 대해 (좋게 꾸미지 않고)

- **앱이 Chrome 페이지만큼 매끄럽다고 보인 적이 없습니다.**
- 실제 폰에서 잰 것은 옛 앱 0.1.0 뿐입니다. 그때 큰 끊김(누르는 동안 화면이 멎는 것)은 없었습니다. 하지만 버리는 프레임과 터치에서 화면까지의 시간은 페이지보다 나빴습니다(터치 → 표시 74.5ms 대 64.1ms).
- 그 뒤 코드 리뷰가 "옛 방식은 지연 약 13ms 와 제때 온 프레임 버리기를 대가로 치렀다"고 짚었습니다. 그래서 화면에 내보내는 시각을 정하는 부분을 **Chrome 페이지와 같은 규칙으로 다시 만들었습니다.**
- 새 규칙은 **폰에서 돌려 본 적이 없습니다.** 옛 폰 기록 17개를 PC 에서 다시 흘려 본 것이 전부입니다. 거기서는 멈춘 갱신 합계가 226 → 155 로 줄었지만, 어떤 기록에서는 오히려 늘었습니다(10 → 28).
- 가상 기기의 수치는 의미가 없습니다(화면 박자가 고르지 않음).
- 따라서 **실제 폰에서 60Hz 와 가변 120Hz 로 다시 재야** 결론을 낼 수 있습니다(8장 7~8번).

**이번 최종 단계에서 고친 코드는 없습니다.** 검증에서 실패한 것이 없었습니다. 시험 스크립트에 시험 하나(`dupapp`)를 더했고 문서를 고쳤습니다.

## 7. 원래 쓰던 도구에서 달라진 것 (알고 계셔야 할 것)

1. **"Wi-Fi 접속 허용" 토글이 없어졌습니다.** 인증 없이 같은 Wi-Fi 의 누구나 화면을 보고 조작할 수 있는 길이었습니다. 대신 **Start → QR → 앱**을 씁니다. QR 을 찍은 기기만 붙습니다. 폰 Chrome 에 PC 주소를 직접 넣어 여는 방법은 이제 없습니다. Chrome 페이지는 USB 나 무선 adb 로만 열립니다.
2. **저장돼 있던 무선 adb 주소를 백업 자리로 옮겼습니다.** 도구가 켜질 때마다 그 주소(폰)로 연결을 시도했기 때문입니다. 지금 `GVR_WirelessAddress` 는 비어 있고 값은 `GVR_WirelessAddress_Backup` 에 있습니다. 되살리려면 창의 무선 연결 칸에서 다시 [연결]하면 저절로 저장됩니다. 또는 Unity 에서 이 한 줄을 실행합니다: `EditorPrefs.SetString("GVR_WirelessAddress", EditorPrefs.GetString("GVR_WirelessAddress_Backup"));`
3. **Play 중에 폰을 USB 로 꽂으면 Unity 가 그 폰에 `adb reverse` 를 겁니다.** 예전부터 있던 동작입니다. 폰의 설정이나 파일은 바꾸지 않습니다. 원하지 않으면 Play 중에 꽂지 마세요.
4. **새 USB 버튼은 가상 기기에만 동작합니다.** 실제 폰에 쓰려면 `GameViewRemoteAppAdb.cs` 위쪽의 `private const bool EMULATOR_ONLY = true;` 를 `false` 로 바꾸고 저장합니다. QR 로 하는 설치와 연결은 이것과 무관합니다.
5. **화면은 한 번에 한 기기에만 나갑니다.** 예전에는 둘이 붙으면 둘 다 화질이 떨어졌습니다. 지금은 나머지가 기다리고 [여기서 보기]로 옮깁니다.
6. **[Stop] 은 USB 의 Chrome 페이지로 보내던 화면도 멈춥니다.**
7. 창 모양이 바뀌었습니다. 예전 설정은 "화질과 고급 설정", "Chrome 페이지로 연결" 구역에 접혀 있습니다.

## 9. 예전 시험이 폰에 남긴 것

- 앱 **0.1.0** 이 설치돼 있습니다. 이 버전에는 첫 실행에서 화면이 안 나오는 결함이 있을 수 있습니다. 8장 5번에서 0.1.2 로 덮어 깔립니다.
- Chrome 의 `http://localhost:7300/` 탭이 **`about:blank` 로 옮겨져 있습니다.** 그 탭에서 주소를 다시 열면 됩니다.
- 파일 **`/data/local/tmp/gvr_shot.png`** 하나가 남아 있습니다(화면 캡처). 지우려면 PC 에서 `adb shell rm /data/local/tmp/gvr_shot.png`. 그냥 두어도 해가 없습니다.
- 폰의 설정과 권한은 바꾸지 않았습니다.

## 10. git 상태 (커밋한 것 없음)

**`GameViewRemoteApp\`**: git 저장소로 만들어져 있지만 커밋이 하나도 없습니다. `android\`, `dist\`, `docs\`, `tools\`, `.gitignore` 전부 새 파일입니다. 빌드 산출물과 시험 기록(`tools\rec\`)은 `.gitignore` 에 들어 있습니다. 서명 키(`android\keystore\`)를 올릴지는 정하셔야 합니다.

**`catjump\`** (브랜치 `develop2`):

- `Assets\04_Scripts\Editor\GameViewRemote\` 폴더 전체와 `GameViewRemote.meta`, `docs\GameViewRemote\` 가 **추적되지 않는 새 파일**입니다. 원래 쓰시던 도구 파일들도 아직 커밋된 적이 없어서, git 으로는 "예전 것"과 "이번에 바뀐 것"을 가를 수 없습니다. 무엇이 바뀌었는지는 이 문서 2장과 개발 문서 17장이 기록입니다.
- **커밋 전에 정할 것 두 가지**
  - `App~\GameViewRemote.apk`: catjump 의 `.gitignore` 가 `*.apk` 를 빼므로 **커밋되지 않습니다.** 옆의 `app.json` 은 커밋됩니다. 팀원이 받으면 앱 파일이 없어 설치 버튼이 숨겨집니다. 앱 파일을 어떻게 나눌지 정해야 합니다.
  - `UserSettings\GameViewRemote.json`: 자동 Start, 고른 PC 주소, 앱 파일 경로를 저장하는 파일입니다. **지금은 없습니다**(기본값만 써서). 창에서 그 설정을 바꾸면 생깁니다. 사람마다 다른 값이라 `.gitignore` 에 넣는 것을 권합니다.
- 이 작업과 무관하게 바뀌어 있는 파일이 있습니다: `ProjectSettings\ProjectSettings.asset`(시작 로고 표시 값 한 줄), `UserSettings\` 의 레이아웃 파일들, `docs\AdRewardAnalysis*.md`. 이번 작업에서 고치지 않았습니다. 커밋할 때 섞이지 않게 보세요.
- 토큰이 든 `Library\GameViewRemote\secret.json` 은 `Library` 안이라 git 밖입니다.

## 11. 권하는 다음 순서

1. 8장 목록을 폰으로 돌립니다. 특히 5(설치), 6(Wi-Fi 연결), 7~8(매끄러움).
2. 매끄러움 수치를 폰에서 다시 잽니다. 페이지보다 나쁘면 화면 내보내는 규칙을 조정합니다.
