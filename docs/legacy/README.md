# 예전 구조의 문서 (보관용)

Game View Remote 시절의 문서입니다. 폰이 PC 로 접속하던 구조(QR → 브라우저 안내 페이지 → APK 서빙, Windows 방화벽 허용, Chrome 페이지 뷰어)를 설명하며, **지금 코드와 맞지 않습니다.** 이름과 경로도 예전 것(`GameViewRemote*`, `kr.co.seeplay.gvr`)입니다.

영상 캡처와 인코딩, 터치 주입, 앱의 디코딩과 프레임 페이싱처럼 바뀌지 않은 부분의 설계 이유와 측정 기록은 여전히 참고가 됩니다.

- `unity/`: Unity 도구의 개발 문서와 사용 가이드, 측정 스크립트(Chrome 페이지용이라 지금은 돌지 않음)
- `app/`: 앱의 조사, 요구 사항, 설계, 리뷰, 최종 보고

지금 구조는 [../DESIGN_DECISIONS.md](../DESIGN_DECISIONS.md) 와 [../PROTOCOL.md](../PROTOCOL.md) 를 보세요.
